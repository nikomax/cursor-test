# cursor-test

A Vue 3 + TypeScript + Vite project.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

This template uses Vue 3 `<script setup>` SFCs. Learn more about [Vue 3](https://vuejs.org/) and [TypeScript setup](https://vuejs.org/guide/typescript/overview.html#project-setup).
